# Source

Downloaded 2026-10-24 from https://github.com/Leonxlnx/taste-skill
(`skills/taste-skill`, branch `main`), MIT licensed — see `LICENSE`.

Only the instructions, references, data library and CSS were copied. The
Node scripts (`scripts/*.mjs`) and JS assets were deliberately left out: they
drive a real browser over CDP and fetch from the network. To get the complete
skill with its scripts, install it through the official installer instead:

    npx skills add Leonxlnx/taste-skill --skill design-taste-frontend
